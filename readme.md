# README - Smart To-Do List Website

## Project Title

**Smart To-Do List Web Application**

## Project Overview

The Smart To-Do List is a web-based task management application that helps users organize their daily activities efficiently. Users can add, complete, delete, and manage tasks through a simple and attractive interface. The application stores data locally in the browser, ensuring tasks remain available even after refreshing the page.

---

## Objective

The main objective of this project is to help users:

* Organize daily tasks.
* Track completed and pending activities.
* Improve productivity and time management.
* Manage tasks through a user-friendly interface.

---

## Features

### 1. Add Tasks

* Users can enter a task in the input field.
* Tasks are added by pressing the **Enter** key.
* Empty tasks are not allowed.

### 2. Task Completion

* Each task contains a checkbox.
* Users can mark tasks as completed.
* Completed tasks are displayed with a strikethrough effect.

### 3. Delete Tasks

* Individual tasks can be removed using the Delete button.

### 4. Clear All Tasks

* Users can remove all tasks at once.
* A confirmation message prevents accidental deletion.

### 5. Due Date Selection

* Users can assign a due date to each task.
* The selected date is displayed below the task.

### 6. Task Statistics

The application displays:

* Total number of tasks.
* Number of completed tasks.

### 7. Local Storage

* Tasks are saved in the browser's local storage.
* Data remains available even after refreshing or reopening the website.

### 8. Responsive Design

* Works on desktops, tablets, and mobile devices.

### 9. Modern User Interface

* Gradient background.
* Attractive task cards.
* Smooth hover effects.
* Clean and professional appearance.

## Working Process

### Step 1: Enter Task

The user types a task into the input field.

### Step 2: Press Enter

The task is added to the task list.

### Step 3: Save Data

The task information is stored in browser local storage.

### Step 4: Manage Tasks

The user can:

* Complete tasks.
* Delete tasks.
* View due dates.

### Step 5: Update Statistics

The application automatically updates:

* Total Tasks
* Completed Tasks

## Limitations

* Data is stored only in the current browser.
* Tasks cannot be shared between devices.
* No user authentication system.
* No cloud synchronization.
